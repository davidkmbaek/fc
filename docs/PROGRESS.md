- **3.2·3.3 팀 상태와 기본 행동** (2026-11-23): `teamState.ts` 팀 모드(attack·defend·loose, 반응 시간 적용)와 홈 위치(공격 시 +12m, 공 x × 0.4, 폭 20% 좁힘). `matchAi.ts` 공 쫓기(무주공일 때 가로채기 시간 최소 1명)·받기·압박(태클 확률)·홈 위치, `ownerDecision.ts` 슛 기대값 → 전진 패스 → (압박 시) 안전 패스 → 드리블(골 방향 ±70° 중 앞이 열린 방향). 사람이 조종하지 않는 우리 팀 선수도 AI. `team` 시나리오에서만 AI(연습 시나리오는 상대가 서 있음).

- 3단계 완료 조건: 헤드리스 20경기(5분) 오류·정체 없음 ✔(최장 정지 5.8초), 경기당 골 0~4(평균 1.35) ✔, 사람 vs AI 재미 — **사용자 확인 필요**. 테스트 204개.
- **4.1·4.2 경기 상태 머신** (2026-11-23): `sim/match.ts` `MatchDirector` PreMatch → SetPiece(킥오프) → InPlay → GoalScored(3초, 실점 팀 킥오프) / OutOfPlay(1초) → SetPiece(스로인·코너킥·골킥) / HalfTime(3초, 진영 교체, 상대 킥오프) → FullTime. 상태는 `SimState.match`(`sim/state.ts`). `sim/setPieces.ts` 재시작 지점·키커(킥오프 FW, 골킥 GK, 그 밖 가장 가까운 필드 선수)·자리(상대는 9.15m, 스로인은 3m 밖). 자리로 최대 2초 이동 후 순간이동, 준비 뒤 키커만 공을 건드림. 스로인은 25m 이내 던지기(슛 → 로빙). AI 키커는 1초 뒤(`ai/setPiece.ts`: 코너는 박스 안 크로스), 사람 팀은 조종이 키커로 넘어오고 8초 안에 안 차면 AI가 대신. 시계는 InPlay에서만, 실제 180초 = 45분. 접촉 처리는 `sim/contact.ts`로 분리. `match` 시나리오(기본값), `team`은 규칙 없는 5:5 연습으로 유지.

## 알려진 문제

- 프로덕션 번들이 약 1.37MB(gzip 358KB)로 Vite의 500KB 경고가 뜬다. Phaser 자체 크기라서 지금은 무시한다.
- 골대가 납작해 보인다: 골문이 화면 좌우에 있고 높이는 화면 위쪽으로 표현해서, 포스트·크로스바가 골라인과 같은 세로줄에 겹친다. 대안(예: z에 x 방향 기울기 추가) 검토 필요 — DESIGN §8 변경 사항이라 승인 후 진행.
- 전력 질주(8 m/s)로 멈춰 있는 공에 다가가면 상대 속도 8 > `CONTROL_MAX_REL_SPEED`(7)라 컨트롤하지 못하고 몸에 맞아 튕겨 나간다. DESIGN 수치대로의 동작인데, 의도한 것인지 플레이 테스트에서 확인 필요.
- AI 경기에서 공이 밖으로 나가는 일이 드물다(20경기에 스로인 4·코너 2·골킥 8). AI가 사이드라인 근처에서 안쪽으로 방향을 트는 경향 — 플레이 테스트 후 판단.
- 미니맵이 화면 아래 가운데를 일부 가린다(반투명). 필요하면 위치·크기를 config에서 조정.
- AI 공격이 소극적이다: 상대가 깊게 내려서면 패스만 돌리고 슛을 거의 안 한다(hard vs easy 10경기: 점유율 81%, 경기당 슛 1.2, 골 0.1). 박스 안으로 드리블해 들어가기·크로스 등 공격 다양화가 필요(4단계 이후 또는 플레이 테스트 후 튜닝).
- 슬라이딩으로 정면에서 공을 맞히면 공이 바로 앞의 상대 몸에 맞고 튕긴다(현실적이지만 정면 슬라이딩은 거의 소용없음). 옆에서 들어가면 잘 뺏긴다.
- 헤드리스 브라우저 테스트에서 페이지를 연 직후 첫 키 입력이 가끔 무시되는 것처럼 보인 적이 있다(짧은 입력 보존 수정 뒤 재현 안 됨). 실제 브라우저에서 첫 입력 전에 캔버스를 클릭하면 확실하다.
- Tweakpane 패널(개발 빌드)이 화면 오른쪽 위를 가려 +x 골대가 일부 안 보인다. 패널 제목을 클릭하면 접힌다. 튜닝 섹션은 접힌 상태로 시작.
- `config.ts`가 300줄을 넘었다(약 320줄). CLAUDE.md 규칙 7("모든 튜닝 수치는 한곳에")을 우선해 나누지 않았다.
- (Claude Code 환경 한정) Git Bash에서 `cd /c/...` 후 `vitest`를 돌리면 Node의 현재 폴더가 소문자 `c:\`가 되어 모든 테스트가 `Cannot read properties of undefined (reading 'config')`로 실패한다. `cd "C:/..."`(대문자)나 PowerShell에서는 정상. VS Code 터미널과 CI에는 영향 없음.
- Phaser 4.2.1 KeyboardPlugin: 키보드 큐를 `POST_STEP`에서만 비우는데 한 스텝 안에서 큐를 여러 번 처리할 수 있고, 중복 방지는 직전 이벤트 1개와만 비교해 같은 keydown이 2~4번 발생했다. Phaser 키보드 이벤트(`keydown-X`)는 쓰지 않는다.
